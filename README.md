## 📋 О проекте

**Defect Management System v2** — это комплексное веб-приложение на Django, созданное для автоматизации процессов выявления, учёта и устранения дефектов на строительных объектах. Система предоставляет единую цифровую платформу для управления качеством работ на всех этапах — от обнаружения проблемы до её полного решения.

Основная цель проекта — заменить бумажный документооборот и разрозненные инструменты учёта, обеспечив полную прозрачность, оперативность взаимодействия и чёткое распределение ответственности (*accountability*) в строительных проектах.

## 🎯 Целевая аудитория и возможности

Система разработана для трёх основных ролей пользователей, каждая из которых получает соответствующий инструментарий:

| Роль | Ключевые возможности |
| :--- | :--- |
| **Инженеры и технические специалисты** | Регистрация новых дефектов, обновление статуса назначенных задач, добавление комментариев и фотоматериалов, отслеживание своего персонального списка заданий. |
| **Менеджеры проектов** | Назначение исполнителей, контроль соблюдения сроков, установка приоритетов задач, мониторинг общего прогресса по проекту. |
| **Руководители и заказчики** | Просмотр сводной отчётности и аналитики по объектам, получение общей картины качества строительства. |

## 🛠 Технологический стек

*   **Backend:** Python 3.x, Django 3.x
*   **Frontend:** HTML, CSS (стилизация на базе шаблонов Django)
*   **База данных:** SQLite (для разработки и тестирования, может быть заменена на PostgreSQL и др.)

## 🚀 Быстрый старт

Эти инструкции помогут вам развернуть копию проекта на локальной машине для целей разработки и тестирования.

### Предварительные требования

*   Python 3.x
*   pip (менеджер пакетов Python)
*   Git

### Установка

1.  **Клонируйте репозиторий:**
    ```
    git clone https://github.com/xtrAtys/defect_management_v2.git
    ```
2. Перейдите в директорию проекта:
   ```
   cd defect_management_v2
   ```
3. Создайте и активируйте виртуальное окружение (рекомендуется):
  ```
   python -m venv venv
   source venv/bin/activate  # Для Linux/Mac
   venv\Scripts\activate  # Для Windows
   ```
4. Установите необходимые зависимости:
   ```
   pip install django
   ```
5. Выполните миграции базы данных:
   ```
   python manage.py migrate
   ```
6. Запустите сервер разработки:
   ```
   python manage.py runserver
   ```
9. Откройте приложение в браузере:
   Перейдите по адресу http://127.0.0.1:8000/.

## 📁 Структура проекта
defect_system/ - Основная конфигурация Django-проекта.

defects/ - Приложение для управления дефектами (модели, представления, формы).

projects/ - Приложение для управления строительными объектами/проектами.

users/ - Приложение для управления пользователями и ролями.

reports/ - Приложение для формирования отчётов и статистики.

templates/ - Общие HTML-шаблоны проекта.

manage.py - Скрипт для управления Django-проектом.

db.sqlite3 - Файл базы данных SQLite (для разработки).
